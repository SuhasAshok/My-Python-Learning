# Day 5 - Password Generator 🔐

## 📌 Project

A Python program that generates a random password based on the number of letters, symbols, and numbers chosen by the user.

## 🧠 What I Learned

- Using `for` loops
- Working with Python lists
- Using `random.choice()`
- Using `random.randint()`
- Using `random.shuffle()`
- Adding elements to lists with `append()`
- Using `range()`
- Converting lists into strings with `join()`
- Working with user input
- Combining multiple concepts to build a complete program

## 💻 Project Example

The user chooses how many:

- Letters
- Symbols
- Numbers

The program then randomly selects the required characters and creates a password.

The characters are shuffled so that the password is not always arranged in the same order.

## 🎯 What I Practiced

This project helped me understand loops, lists, randomisation, and how to manipulate data to create a useful program.
