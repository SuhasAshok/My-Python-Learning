# Day 2 - Tip Calculator 🧮

## 📌 Project

A simple Python program that calculates how much each person should pay when splitting a bill, including a tip.

## 🧠 What I Learned

- Working with different **data types**
- Type conversion using `int()` and `float()`
- Performing mathematical calculations
- Using variables to store data
- String manipulation
- F-strings for formatted output
- Rounding numbers using `round()`

## 💻 Project Example

The program asks the user for:

1. The total bill
2. The percentage of tip they want to give
3. The number of people sharing the bill

It then calculates the total amount each person should pay.

## 🎯 What I Practiced

This project helped me practice working with numbers, converting user input into the correct data types, performing calculations, and formatting the final output.
