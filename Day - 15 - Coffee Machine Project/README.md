# Day 15 - Coffee Machine ☕

## 📌 Project

A text-based coffee machine program that allows the user to order different types of coffee and manages resources such as water, milk, coffee, and money.

## 🧠 What I Learned

- Using functions to organise a program
- Working with dictionaries
- Using nested dictionaries
- Using `if`, `elif`, and `else` statements
- Using `while` loops
- Creating and updating variables
- Comparing values
- Working with user input
- Using Boolean values
- Checking available resources
- Managing money and calculating change
- Structuring a larger program into separate functions

## 💻 Project Example

The coffee machine allows the user to choose from different drinks, such as:

- Espresso
- Latte
- Cappuccino

The program checks whether enough resources are available, processes the payment, prepares the selected drink, and updates the remaining resources.

The user can also enter a command to view the machine's current resource report.

## 🎯 What I Practiced

This project helped me combine dictionaries, functions, loops, conditions, and variables to build a more complex program that simulates the behaviour of a real-world coffee machine.
