# Day 23 - Turtle Crossing Capstone Project 🐢🚗

## 📌 Project

A classic Turtle Crossing game built using Python's Turtle graphics and Object-Oriented Programming.

The game features a player-controlled turtle, randomly generated cars, collision detection, level progression, increasing car speed, and a game-over sequence.

## 🧠 What I Learned

- Building a complete game using **Object-Oriented Programming**
- Creating and working with multiple classes
- Using **inheritance** with the Turtle class
- Creating a `Player` class for player controls
- Creating a `CarManager` class for managing multiple cars
- Creating a `Scoreboard` class for tracking the level
- Managing multiple objects using lists
- Detecting collisions between the turtle and cars
- Detecting when the player reaches the finish line
- Randomly generating cars with different colours and positions
- Increasing the car speed as the level progresses
- Using keyboard events for player controls
- Using `time.sleep()` and `screen.tracer()` to control the game loop
- Organising a larger project across multiple Python files

## 🎮 Controls

- **W** → Move the turtle forward

## 💻 Game Features

- 🐢 Player-controlled turtle
- 🚗 Randomly generated moving cars
- 🎨 Random car colours
- 💥 Car collision detection
- 🏁 Finish line detection
- 📊 Level tracking
- ⚡ Car speed increases with each level
- 🔄 Player returns to the starting position after successfully crossing
- 💀 Game Over sequence
- 🖥️ 600 × 600 game screen

## 🎯 What I Practiced

This project helped me bring together multiple classes and objects to create a complete game.

I practiced Object-Oriented Programming, inheritance, list management, collision detection, keyboard event handling, randomisation, game loops, level progression, and managing the state of multiple game objects.
