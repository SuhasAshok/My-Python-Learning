# Day 3 - Treasure Island 🏝️

## 📌 Project

A text-based adventure game where the player makes choices to find the hidden treasure. Different decisions lead to different outcomes.

## 🧠 What I Learned

- Using `if`, `elif`, and `else` statements
- Conditional logic
- Comparison operators
- Logical operators
- Nested `if` statements
- Using `input()` to get user choices
- Controlling the flow of a program based on user input

## 💻 Project Example

The player is presented with different situations and must choose between options.

For example:

1. Choose which direction to go.
2. Choose how to cross an obstacle.
3. Choose between different doors.

The choices determine whether the player finds the treasure or loses the game.

## 🎯 What I Practiced

This project helped me understand how conditional statements control the flow of a program and how multiple decisions can be combined to create a simple interactive game.
