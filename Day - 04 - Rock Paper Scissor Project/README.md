# Day 4 - Rock Paper Scissors 🪨📄✂️

## 📌 Project

A simple Rock Paper Scissors game where the player competes against the computer.

## 🧠 What I Learned

- Working with Python **lists**
- Using `random.choice()` to select a random item
- Using `random.randint()` to generate random numbers
- Indexing lists
- Using `if`, `elif`, and `else` statements
- Comparison operators
- Logical operators
- Combining multiple concepts to create a game

## 💻 Project Example

The player chooses:

- Rock 🪨
- Paper 📄
- Scissors ✂️

The computer randomly selects one of the three choices. The program then compares both choices and determines whether the player wins, loses, or draws.

## 🎯 What I Practiced

This project helped me practice working with lists, randomisation, indexing, and conditional logic while building a complete game.
