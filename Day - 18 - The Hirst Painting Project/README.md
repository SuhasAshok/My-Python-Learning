# Day 18 - Hirst Painting 🎨

## 📌 Project

A Python program that recreates the style of Damien Hirst's famous spot paintings using Turtle graphics.

## 🧠 What I Learned

- Using the `turtle` module
- Creating and controlling a Turtle object
- Drawing using Turtle graphics
- Changing the turtle's position and heading
- Using loops to repeat actions
- Working with Python lists
- Using tuples to store RGB colour values
- Extracting colours from an image
- Using the `colorgram` module to extract colours from an image
- Using random colours from a list
- Using `turtle.colormode()` for RGB colours
- Using functions to organise code
- Working with coordinates and screen positioning

## 💻 Project Example

The program creates a grid of coloured dots using Turtle graphics.

The colours are extracted from an existing image and randomly selected to create a new spot painting inspired by Hirst's artwork.

## 🎯 What I Practiced

This project helped me combine loops, lists, functions, external modules, RGB colours, and Turtle graphics to create a visual Python project.
