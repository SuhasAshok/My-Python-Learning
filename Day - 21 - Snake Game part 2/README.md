# Day 21 - Snake Game Part 2 🐍

## 📌 Project

The second part of the Snake Game, where the basic snake movement from Day 20 is expanded into a complete playable game with food, scoring, snake growth, and collision detection.

## 🧠 What I Learned

- Creating classes using Object-Oriented Programming
- Using **inheritance** with Turtle classes
- Creating a `Food` class that inherits from `Turtle`
- Creating a `Scoreboard` class that inherits from `Turtle`
- Creating reusable methods for different game components
- Using `random.randint()` to generate random food positions
- Detecting collisions using `distance()`
- Detecting collision with the walls using coordinates
- Detecting collision between the snake's head and its tail
- Extending the snake by adding new segments
- Updating the scoreboard during the game
- Using `clear()` to update displayed information
- Managing game state with Boolean variables
- Organising a larger program into multiple Python files

## 💻 Project Example

The Snake Game now includes:

- 🐍 A controllable snake
- 🍎 Food that appears at random positions
- 📈 A score that increases when food is eaten
- 🐍 Snake growth after eating food
- 🧱 Wall collision detection
- 💥 Tail collision detection
- 🏆 A `GAME OVER` message when the snake crashes

The player controls the snake using:

- **W** → Up
- **S** → Down
- **A** → Left
- **D** → Right

## 🎯 What I Practiced

This project helped me apply Object-Oriented Programming concepts such as inheritance, classes, objects, and methods in a complete game.

I also practiced collision detection, managing game state, updating a scoreboard, and organising a larger Python project across multiple files.
