# Day 6 - Reeborg's World 🤖

## 📌 Project

A series of programming challenges completed using **Reeborg's World**, where I controlled a robot by writing Python code.

## 🧠 What I Learned

- Defining and calling functions
- Using `while` loops
- Understanding indentation
- Using conditions with `if`
- Using `while` with conditions
- Using `not` to reverse a condition
- Using built-in functions such as `move()`, `turn_left()`, and `at_goal()`
- Creating reusable functions to simplify code
- Understanding how loops can repeat instructions until a condition is met

## 💻 Project Example

The challenges required Reeborg to navigate different environments and reach the goal by following instructions written in Python.

I practiced creating functions and using `while` loops to make the robot repeat actions until it reached the required condition.

## 🎯 What I Practiced

This day helped me understand how functions and loops work together and how conditions can be used to control the flow of a program.
