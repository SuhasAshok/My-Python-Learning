# Day 17 - Quiz Game ❓

## 📌 Project

A quiz game built using Python and Object-Oriented Programming. The program presents questions to the user, checks their answers, and keeps track of their score.

## 🧠 What I Learned

- Creating classes and objects
- Using constructors with `__init__()`
- Creating instance attributes and methods
- Working with lists and dictionaries
- Using `for` loops
- Using `if` statements
- Working with Boolean values
- Using user input
- Tracking and updating a score
- Importing classes from different Python files
- Using modules to organise code
- Working with objects and passing them between classes

## 💻 Project Example

The quiz contains a series of questions with multiple-choice answers.

The program:

1. Displays a question.
2. Gets the user's answer.
3. Checks whether the answer is correct.
4. Updates the score.
5. Moves to the next question.

At the end, the user's final score is displayed.

## 🎯 What I Practiced

This project helped me apply Object-Oriented Programming concepts in a practical project and understand how multiple classes and modules can work together.
