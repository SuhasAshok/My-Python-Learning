# Day 27 - Mile to Kilometers Converter 🖥️📏

## 📌 Project

A simple Mile to Kilometers converter built using **Python** and the **Tkinter** library.

The program allows the user to enter a distance in miles and converts it into kilometers using a graphical user interface.

## 🧠 What I Learned

- Introduction to **Graphical User Interfaces (GUI)**
- Creating GUI applications using **Tkinter**
- Creating and configuring a `Tk()` window
- Creating and configuring Tkinter widgets
- Using Tkinter widgets such as `Label`, `Entry`, and `Button`
- Getting user input from an `Entry` widget using `.get()`
- Updating widget properties using `.config()`
- Using Tkinter geometry managers:
  - `pack()`
  - `place()`
  - `grid()`
- Positioning widgets using rows and columns with `grid()`
- Positioning widgets using coordinates with `place()`
- Arranging widgets using `pack()`
- Setting default values for optional function arguments
- Using `*args` for multiple positional arguments
- Using `**kwargs` for multiple keyword arguments
- Connecting buttons to functions using the `command` parameter
- Using `mainloop()` to keep the GUI application running
- Converting strings to numbers using `float()`
- Rounding calculated values using `round()`

## 💻 Project Features

- 🖥️ Graphical user interface
- ⌨️ Miles input field
- 🔢 Converts miles into kilometers
- 📊 Displays the calculated kilometer value
- 🔘 Calculate button
- 📐 Uses the conversion rate of 1 mile = 1.609 kilometers
- 🧩 Built using Python's Tkinter library

## 🎯 What I Practiced

This project introduced me to building graphical user interfaces with Python using Tkinter.

I practiced creating windows and widgets, positioning widgets using the `pack()`, `place()`, and `grid()` geometry managers, retrieving user input, updating labels, connecting buttons to functions, and working with optional function arguments.
