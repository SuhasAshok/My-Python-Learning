# Day 1 - Band Name Generator 

## 📌 Project

A simple Python program that generates a band name by combining the user's **city name** and **pet's name**.

## 🧠 What I Learned

- Using `print()` to display information
- Using `input()` to get information from the user
- Storing information in **variables**
- Working with **strings**
- String concatenation
- Using `len()` to find the length of a string
- Understanding string subscripting/indexing
- Basic Python syntax and formatting

## 💻 Project Example

The program asks the user:

1. What city did you grow up in?
2. What is the name of your pet?

It then combines the two answers to generate a band name.

## 🎯 What I Practiced

This project helped me practice taking user input, storing it in variables, and using that information to produce an output.
