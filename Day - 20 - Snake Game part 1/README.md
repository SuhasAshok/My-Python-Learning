# Day 20 - Snake Game Part 1 🐍

## 📌 Project

The first part of a Snake Game built using Python's Turtle graphics. The project focuses on creating the snake, animating its movement, controlling it with the keyboard, and introducing Object-Oriented Programming.

## 🧠 What I Learned

- Creating a `Snake` class
- Creating and managing multiple objects
- Using instance attributes and methods
- Understanding object state
- Working with the Turtle coordinate system
- Animating objects using `screen.tracer()` and `screen.update()`
- Using `time.sleep()` to control animation speed
- Handling keyboard input with event listeners
- Using `onkey()` to control the snake
- Moving multiple objects together
- Using loops to update the position of objects
- Using constants to make code easier to manage
- Preventing the snake from making an immediate 180-degree turn

## 💻 Project Example

The program creates a snake made up of three square segments.

The snake continuously moves across the screen, and the player can control its direction using:

- **W** → Up
- **S** → Down
- **A** → Left
- **D** → Right

The snake's body segments follow the position of the segment in front of them, creating the basic movement of a Snake game.

## 🎯 What I Practiced

This project helped me understand how to create a class to manage multiple Turtle objects and how object-oriented programming can be used to structure a game.

I also practiced animation, keyboard event handling, coordinates, loops, and managing the state of multiple objects.
