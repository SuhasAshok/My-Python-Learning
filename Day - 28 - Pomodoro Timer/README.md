# Day 28 - Pomodoro Timer 🍅⏱️

## 📌 Project

A Pomodoro Timer application built using **Python** and the **Tkinter** library.

The application uses the Pomodoro technique with work sessions, short breaks, and long breaks. It also keeps track of completed work sessions using checkmarks.

## 🧠 What I Learned

- Creating a GUI application using **Tkinter**
- Working with the Tkinter `Canvas` widget
- Adding images to a Tkinter application using `PhotoImage`
- Creating text and images on a Canvas
- Creating a countdown timer using `window.after()`
- Cancelling scheduled Tkinter events using `after_cancel()`
- Using `math.floor()` for time calculations
- Converting minutes into seconds
- Using the modulo operator `%` to determine different timer sessions
- Creating work sessions and break sessions
- Creating short breaks and long breaks
- Dynamically updating widget properties using `.config()`
- Dynamically updating Canvas text using `.itemconfig()`
- Using global variables to maintain timer state
- Tracking the number of completed sessions
- Using loops to generate completed-session checkmarks
- Resetting the application state
- Working with GUI application logic and state

## 💻 Project Features

- 🍅 Pomodoro work timer
- 🧘 Short break timer
- 🛌 Long break timer
- ⏱️ Automatic countdown
- 🔄 Automatically switches between work and break sessions
- ✅ Tracks completed work sessions
- 🔄 Reset button to restart the timer
- 🖥️ Graphical user interface built with Tkinter
- 🍅 Tomato-themed timer interface

## 🎯 What I Practiced

This project helped me build a more interactive GUI application using Tkinter.

I practiced working with the Canvas widget, images, countdown timers, scheduled functions, dynamic widget updates, application state, and event-driven programming.

I also learned how to implement the Pomodoro technique by automatically switching between work sessions and different break durations.
