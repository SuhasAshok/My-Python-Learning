# Day 9 - Blind Auction 🔨

## 📌 Project

A Python program that simulates a blind auction where multiple bidders can enter their names and bids. The program determines the highest bidder at the end.

## 🧠 What I Learned

- Working with Python **dictionaries**
- Adding and accessing key-value pairs
- Using `while` loops
- Using `if`, `elif`, and `else` statements
- Nesting data structures
- Using `max()` to find the highest value
- Creating and calling functions
- Clearing the console between rounds
- Using `input()` to collect user information
- Combining dictionaries, loops, functions, and conditional logic

## 💻 Project Example

The program asks each bidder for:

1. Their name
2. Their bid amount

The bids are stored in a dictionary. The program continues accepting bidders until there are no more participants.

At the end, the program compares the bids and announces the person with the highest bid.

## 🎯 What I Practiced

This project helped me understand dictionaries, how to store related information using key-value pairs, and how loops and functions can be combined to create an interactive program.
