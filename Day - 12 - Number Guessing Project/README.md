# Day 12 - Number Guessing Game 🎯

## 📌 Project

A number guessing game where the player tries to guess a randomly generated number between 1 and 100.

## 🧠 What I Learned

- Using `random.randint()` to generate random numbers
- Working with functions
- Using function parameters and return values
- Using `while` loops
- Using `if`, `elif`, and `else` statements
- Working with Boolean values
- Using comparison operators
- Managing the number of attempts based on the selected difficulty
- Using global and local variables
- Creating a game with multiple difficulty levels

## 💻 Project Example

The computer generates a random number between 1 and 100.

The player chooses a difficulty:

- **Easy** → More attempts
- **Hard** → Fewer attempts

The player continues guessing, and the program provides hints indicating whether the guess is too high or too low.

The game ends when the player guesses the correct number or runs out of attempts.

## 🎯 What I Practiced

This project helped me practice functions, loops, conditions, randomisation, and managing game state while creating a program with different difficulty levels.
