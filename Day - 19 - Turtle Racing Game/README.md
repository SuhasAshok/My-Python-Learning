# Day 19 - Turtle Racing Game 🐢🏁

## 📌 Project

A Turtle Racing game where the player bets on a turtle color and watches six turtles race to the finish line.

## 🧠 What I Learned

- Understanding **object instances**
- Understanding **object state**
- Creating multiple instances from the same class
- Working with the `Turtle` class
- Using lists to store multiple turtle objects
- Using `for` loops to work with multiple objects
- Using `random.randint()` to generate random movement
- Using `xcor()` to check a turtle's position
- Working with the Turtle coordinate system
- Using `screen.textinput()` to get user input
- Using Boolean variables to control a game
- Using higher-order functions and event listeners
- Organising a program using objects and their attributes/methods

## 💻 Project Example

The program creates six turtles with different colors and places them at different starting positions.

The player is asked to choose which turtle they think will win.

Once the race starts, each turtle moves a random distance on every turn. The race continues until one turtle reaches the finish line.

The program then checks whether the player's chosen turtle won or lost.

## 🎯 What I Practiced

This project helped me understand how multiple objects can be created from the same class and how each object can maintain its own state.

I also practiced working with coordinates, object attributes and methods, lists of objects, and random movement to create an interactive Turtle game.
