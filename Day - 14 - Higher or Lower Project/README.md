# Day 14 - Higher or Lower 🎯

## 📌 Project

A text-based Higher or Lower game where the player tries to guess which celebrity or public figure has more followers on social media.

## 🧠 What I Learned

- Working with Python dictionaries
- Using lists of dictionaries
- Creating and using functions
- Function parameters and return values
- Using `random.choice()` to select random items
- Using `while` loops
- Using `if`, `elif`, and `else` statements
- Comparing values
- Keeping track of the player's score
- Using Boolean values
- Structuring a larger program into smaller functions

## 💻 Project Example

The game displays two randomly selected accounts and provides information about each one.

The player must guess which account has a higher number of followers.

If the answer is correct, the player's score increases and the game continues with a new comparison. The game ends when the player makes an incorrect guess.

## 🎯 What I Practiced

This project helped me combine dictionaries, lists, functions, loops, randomisation, and conditional logic to create a more complex interactive game.
