# Day 13 - Debugging 🐛

## 📌 Project

A day focused on learning how to find and fix errors and bugs in Python programs.

## 🧠 What I Learned

- Understanding common types of errors
- Identifying bugs in Python code
- Using debugging techniques to find problems
- Reading error messages and tracebacks
- Using `print()` to help identify problems
- Checking code step by step
- Using breakpoints and the debugger
- Testing code to find unexpected behaviour
- Fixing syntax and logic errors

## 💻 Project Example

Instead of building one major project, this day focused on debugging several pieces of Python code.

The exercises contained intentional errors that needed to be identified and corrected.

## 🎯 What I Practiced

This day helped me understand that debugging is an important part of programming and taught me how to systematically find and fix problems in Python code.
