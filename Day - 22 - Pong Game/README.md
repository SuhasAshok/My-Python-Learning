# Day 22 - Pong: The Famous Arcade Game 🏓

## 📌 Project

A classic Pong game built using Python's Turtle graphics and Object-Oriented Programming.

The game features two paddles, a moving ball, collision detection, scoring, and increasing ball speed as the game progresses.

## 🧠 What I Learned

- Building a larger project using **Object-Oriented Programming**
- Creating and working with multiple classes
- Using **inheritance** with the Turtle class
- Creating a `Paddle` class for player controls
- Creating a `Ball` class for ball movement and bouncing
- Creating a `Scoreboard` class for keeping track of scores
- Detecting collisions with walls and paddles
- Using the Turtle coordinate system
- Handling keyboard events
- Using `time.sleep()` to control game speed
- Increasing the ball speed as the game progresses
- Resetting the ball after a player misses
- Organising a project across multiple Python files

## 🎮 Controls

### Left Player
- **W** → Move Up
- **S** → Move Down

### Right Player
- **↑** → Move Up
- **↓** → Move Down

## 💻 Game Features

- 🏓 Two-player Pong gameplay
- ⚪ Ball bouncing off the walls
- 🏓 Paddle collision detection
- 📊 Score tracking
- ⚡ Ball speed increases after paddle collisions
- 🔄 Ball resets after a player misses
- 🖥️ 800 × 600 game screen

## 🎯 What I Practiced

This project helped me bring together multiple classes and objects into a single working game.

I practiced Object-Oriented Programming, inheritance, collision detection, keyboard event handling, game loops, and managing the state of different game objects.
