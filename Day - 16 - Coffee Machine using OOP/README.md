# Day 16 - Object-Oriented Programming (OOP) 🐍

## 📌 Project

A coffee machine program built using Object-Oriented Programming concepts and Python classes.

## 🧠 What I Learned

- Understanding **Object-Oriented Programming (OOP)**
- Creating classes
- Creating objects from classes
- Using constructors with `__init__()`
- Understanding attributes and methods
- Using instance attributes
- Using instance methods
- Passing objects as arguments
- Importing classes from modules
- Working with multiple Python files
- Understanding how objects can interact with each other
- Organising code using classes

## 💻 Project Example

The coffee machine program was recreated using classes to represent different parts of the machine, such as:

- **CoffeeMaker** - manages resources and makes coffee
- **MoneyMachine** - handles payments and money
- **Menu** - manages the available drinks

Each class is responsible for its own data and behaviour, making the program more organised and easier to maintain.

## 🎯 What I Practiced

This project introduced me to Object-Oriented Programming and helped me understand how classes and objects can be used to structure larger Python programs.
