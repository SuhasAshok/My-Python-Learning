# Day 11 - Blackjack 🃏

## 📌 Project

A text-based Blackjack game where the player competes against the computer. The goal is to get a hand value as close to 21 as possible without going over.

## 🧠 What I Learned

- Working with Python lists
- Using functions with parameters and return values
- Using `random.choice()` to select cards
- Working with dictionaries
- Using `while` loops
- Using `for` loops
- Using `if`, `elif`, and `else` statements
- Using Boolean values
- Creating and using helper functions
- Handling special cases such as the Ace being worth 1 or 11
- Using conditional logic to determine the winner

## 💻 Project Example

The player and computer are each dealt cards from a deck.

The player can choose to:

- **Hit** and draw another card
- **Stand** and keep their current hand

The computer then plays according to the game rules. The program calculates the final scores and determines the winner.

## 🎯 What I Practiced

This project helped me combine functions, lists, loops, randomisation, and conditional logic to create a more complex game with multiple possible outcomes.
