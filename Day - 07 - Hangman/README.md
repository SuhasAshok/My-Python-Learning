# Day 7 - Hangman 🎯

## 📌 Project

A text-based Hangman game where the player tries to guess a hidden word one letter at a time.

## 🧠 What I Learned

- Working with Python lists
- Using `random.choice()` to select a random word
- Using `for` loops
- Using `while` loops
- Working with strings
- Using `if`, `elif`, and `else`
- Using the `in` operator to check whether a letter exists in a word
- Tracking the player's guesses and lives
- Using string formatting
- Combining multiple Python concepts to build a complete game

## 💻 Project Example

The program randomly selects a word and displays blanks representing the letters.

The player guesses letters one at a time. Correct guesses reveal the letters, while incorrect guesses reduce the number of remaining lives.

The game continues until the player either guesses the word or runs out of lives.

## 🎯 What I Practiced

This project helped me practice loops, lists, strings, conditions, randomisation, and tracking game state while building a complete interactive game.
