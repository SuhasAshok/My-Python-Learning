# Day 26 - NATO Phonetic Alphabet Project 📻🔤

## 📌 Project

A simple NATO Phonetic Alphabet converter built using **Python** and the **Pandas library**.

The program takes a word from the user and converts each letter into its corresponding NATO phonetic alphabet code.

For example, entering `HELLO` produces:

```text
['Hotel', 'Echo', 'Lima', 'Lima', 'Oscar']
```

## 🧠 What I Learned

- Creating **list comprehensions**
- Creating **dictionary comprehensions**
- Reading CSV data using Pandas
- Working with Pandas DataFrames
- Iterating through DataFrame rows using `iterrows()`
- Creating dictionaries from DataFrame data
- Accessing dictionary values using keys
- Converting user input to uppercase using `.upper()`
- Using comprehensions to process strings
- Combining Pandas with dictionaries
- Working with structured data from CSV files

## 💻 Project Features

- 🔤 Converts letters into NATO phonetic codes
- ⌨️ Accepts a word from the user
- 📄 Reads the NATO alphabet from a CSV file
- 📊 Uses Pandas to process the CSV data
- 📖 Creates a dictionary mapping letters to NATO codes
- ⚡ Uses list comprehension to generate the final output

## 🎯 What I Practiced

This project helped me understand how **list comprehensions and dictionary comprehensions** can make Python code shorter and more efficient.

I also practiced working with CSV data using Pandas and converting that data into a dictionary that could be used to look up the NATO code for each letter.
