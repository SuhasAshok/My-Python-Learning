# Day 10 - Calculator 🧮

## 📌 Project

A simple calculator program that performs basic mathematical operations based on the user's input.

## 🧠 What I Learned

- Creating functions with parameters
- Returning values from functions using `return`
- Using function outputs in other parts of a program
- Using dictionaries to store and access functions
- Working with `while` loops
- Using `if`, `elif`, and `else` statements
- Using mathematical operators
- Handling user input
- Reusing functions to avoid repeating code

## 💻 Project Example

The calculator allows the user to enter a number and choose a mathematical operation such as:

- Addition `+`
- Subtraction `-`
- Multiplication `*`
- Division `/`

The program performs the selected operation and displays the result. The user can then continue calculating with the previous result or start a new calculation.

## 🎯 What I Practiced

This project helped me understand how functions can take inputs and return outputs, and how functions can be stored in a dictionary to make a program more organized and reusable.
