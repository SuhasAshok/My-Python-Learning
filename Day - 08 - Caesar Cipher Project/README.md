# Day 8 - Caesar Cipher 🔐

## 📌 Project

A text-based encryption and decryption program that uses the Caesar Cipher technique to shift letters by a specified number of positions in the alphabet.

## 🧠 What I Learned

- Defining and using functions
- Function parameters and arguments
- Working with Python lists
- Using `for` loops
- Using `if` statements
- Using the `range()` function
- Working with strings and string indexing
- Using the modulo `%` operator
- Handling user input
- Combining functions, loops, lists, and conditions

## 💻 Project Example

The program allows the user to:

1. Enter a message.
2. Choose whether to **encode** or **decode** the message.
3. Enter a shift number.

The program then shifts each letter by the specified amount to encrypt or decrypt the message.

## 🎯 What I Practiced

This project helped me understand function parameters, loops, string manipulation, list indexing, and how the modulo operator can be used to wrap around the alphabet.
